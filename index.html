Bingo Splash Board helps you host and manage your own Bingo games.

Clear the board for a new game with a reset.
Set the winning Bingo pattern.
Randomly draw a Bingo ball.
Make the board fullscreen.

 

Change how the board looks with themes.
Toggle the balls drawn/remaining counter.
Hide the board for a tougher game or intermission pause.
Manually edit the board by clicking on letters.

Select individual balls if you're drawing separately.

Use keyboard shortcuts.

Draw balls with the space bar.

Reset the board with the r key.

Other Shortcuts

f - Toggle fullscreen

t - Go to Themes page

w - Go to Winning Pattern page

enter - Go to splash board from title

v - Toggle balls drawn/remaining

x - Hide/show board

Add ?splashboard to the end of the URL to quickly load the splash board.
